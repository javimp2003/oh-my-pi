Search the web for current or external information: library/API docs, release notes, versions, error messages, news, anything past your training data or that you're unsure of. Returns sources with excerpts (sometimes a synthesized answer); link citations.
Known URL → `read`. Prefer this over fetching search-engine pages via `eval`, `bash`, or the browser. One or two well-formed queries usually suffice; then `read` the best source instead of re-searching.
Operators: site: or -site:, after: or before: YYYY-MM-DD, inurl:, intitle:, filetype:, "phrase", -term, OR.{{#if xSearch}} X posts/reactions → `site:x.com`, `site:x.com/<handle>`, or `from:<handle>`; `-from:<handle>` excludes.{{/if}}
